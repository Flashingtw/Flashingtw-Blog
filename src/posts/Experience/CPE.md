# 第一題：照著公式寫也能寫錯

先打開第一題看看，是一題遞迴題，照著公式寫就好。

題目寫的是 `f(N) = f(f(N+11))`，結果我寫成：

```cpp
return f(N+11);
```

然後就卡了大概五分鐘。

不是啊，外面還有一層 `f`，你怎麼可以直接把他吃掉。
很好笑，照抄都能抄錯ww。

# 第二題：空字串很陰險

第二題是字串比對，看起來還好，但很陰險的是他會有空字串。
所以要用 `getline` 讀。

CPP reference 救了我，感謝文件，沒有你我可能又要卡住了（

呃然後還有一題水題，但我忘記是啥了。
總之有寫出來，記憶沒有跟著 AC 一起留下來。

# 第四題：英文跟 deque 的雙重摧殘

接下來剩下兩個多小時，我打開了第四題。

經過了我相當爛的英文閱讀能力，還有單字翻譯器的摧殘後，我大概看懂了。
就是一個數數字，然後要中間最小、往外擴張，還要最小字典序……還是最大？
忘了，總之當時大概是這樣理解的（

我想用 `deque` 實作，然後就寫爛了。

大概花了四十分鐘，甚至更多，一直戳一直改，最後發現我寫不出來。
好，先放下，開第五題看看。

# 第五題：一直往 3 sum 想

題目是給定一個數字集合，求滿足 `a+b+c=d` 的最大的 `d`。

我一直往 3 sum 去想，想說我要弄個 $O(N^2 \log N)$ 啊。
結果想著想著，寫著寫著，又寫爛了（

很靠邀，反正我放棄了。

看了看範圍：$n,m \le 20$，$q \le 10$。

哎我操，爆搜囉。
